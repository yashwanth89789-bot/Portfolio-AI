## 🌟 Overview

**Portfolio Booster** turns mediocre resumes and portfolios into high-converting, recruiter-ready assets. Whether scraping live portfolio URLs via a secure proxy or pasting raw resumes, the platform runs deep structural, semantic, and ATS compliance diagnostics to surface immediate high-ROI enhancements.

## 🔬 Deep Dive: Core Engines

### 1. Portfolio Health Score & Circular Gauge
* **Animated SVG Arc**: Smooth radial progress rendering calculated from geometric circumference calculations.
* **Tier Stratification**:
  * `85 - 100`: **Elite Profile** (Emerald) — High-volume Tier 1 interview readiness.
  * `70 - 84`: **Competitive** (Indigo) — Strong baseline requiring minor metrics refinement.
  * `50 - 69`: **Needs Refinement** (Amber) — Suffers from passive voice or missing tech stack depth.
  * `00 - 49`: **At Risk** (Rose) — High probability of automated ATS rejection.
* **Sub-Metric Quick-Bar**: Instant summary of ATS Match, Metrics Density, Technical Depth, and Action Verbs.

### 2. Bullet Point Impact & Passive Phrase Inspector
* **Tokenized Phrase Diagnostics**: The analyzer decomposes bullet points into categorized tokens:
  * 🔴 **Passive Voice**: *"was responsible for"*, *"tasked with"*, *"duties included"*
  * 🟡 **Weak Auxiliary Verbs**: *"worked on"*, *"assisted in"*, *"helped team"*
  * 🟢 **Power Action Verbs**: *"Spearheaded"*, *"Architected"*, *"Optimized"*, *"Pioneered"*
  * 🔵 **Quantifiable Metric Proofs**: Percentages (`35%`), latency reductions (`45ms`), dollar amounts (`$65k`), and scale (`250k+ QPS`).
* **Formula Rewriting Engine**: Generates 4 tailored rewrite variations for any input:
  1. **Google X-Y-Z Formula**: *"Accomplished [X], as measured by [Y], by doing [Z]"*
  2. **Executive & Leadership**: Focused on cross-functional alignment and bottom-line ROI.
  3. **Deep Technical Architecture**: Emphasizes system resilience, concurrency, and throughput.
  4. **1-Line ATS Punch**: High-density concise bullet optimized for quick recruiter skimming.

### 3. 6-Dimensional Competency Radar
* Dynamic radar chart visualizing candidate competency distribution.
* Prevents blind spots by highlighting imbalances between pure technical depth and measurable business impact.

### 4. ATS Keyword & Frequency Density Matcher
* Curated taxonomies across **Frontend**, **Full-Stack / Backend**, **AI / Data**, **Mobile**, and **DevOps** tracks.
* Categorizes keywords into **Present** vs. **Missing Critical** with exact occurrence frequencies.

### 5. Simulated 6-Second Recruiter Heatmap
* Emulates modern recruiter scanning behaviors (F-shape and Z-pattern scanning).
* Surfaces high-attention hotspots and warns against low-contrast or buried achievements.

### 6. Multi-Channel Launch & Cold Outreach Studio
* **Twitter / X Threads**: High-converting showcase format highlighting problem, stack, and demo.
* **LinkedIn Story Post**: Professional narrative on architectural trade-offs and business impact.
* **Product Hunt Pitch**: Structured tagline, key highlights, and early adopter call to action.
* **Recruiter Cold DM**: Concise, value-forward intro template tailored for senior technical recruiters.

## 🏗️ System Architecture & Data Flow

```
[ Client Browser (React 19 + Tailwind v4) ]
   │
   ├── 1. Direct Text Submission OR URL Input
   │        │
   │        ▼ (GET /api/fetch-url?url=...)
   ├── 2. Express Backend Proxy (Cheerio HTML extraction)
   │        │
   │        ▼
   ├── 3. Client-Side Analyzer Engine (analyzerEngine.ts)
   │        ├── Tokenizes bullet points & detects passive phrasing
   │        ├── Computes 0-100 Health Score & Sub-scores
   │        ├── Matches ATS role taxonomies
   │        └── Synthesizes Google X-Y-Z rewrites
   │
   └── 4. State & Presentation Layer
            ├── PortfolioHealthScore (Animated SVG Radial Gauge)
            ├── ScorecardTab & Competency Radar (Recharts)
            ├── BulletPointLabTab & BulletImpactCard (Interactive Tester)
            ├── KeywordsTab, RecruiterHeatmapTab, LaunchCopyTab
            └── AiAssistantChat & ExportModal (JSON / Markdown)
```

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or Bun
- npm / yarn / pnpm

### Installation & Local Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/portfolio-booster.git
   cd portfolio-booster
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Launch the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Production Build & Deployment

Portfolio Booster is configured for standalone container deployment on Google Cloud Run and similar platforms:

```bash
# 1. Compile client assets and bundle backend server into dist/server.cjs
npm run build

# 2. Start the production CommonJS server
npm run start
```

### Health Check Endpoint
- `GET /api/health` returns `{ "status": "ok" }` for container orchestrator readiness and liveness checks.
